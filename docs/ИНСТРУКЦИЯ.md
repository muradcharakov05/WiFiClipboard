# Мост буфера · версия 7.3.1

Обновлено оформление Windows: разделы расположены в карточках, диалоги оформлены в общей цветовой гамме.

Исправлена смена Wi-Fi: IP-адреса, QR-код и mDNS обновляются без перезапуска программы. Сохранённые подключения остаются действующими.

Исправлено окно Windows: кнопка «Забыть все iPhone» закреплена внизу, а размер окна учитывает доступную область экрана над панелью задач. Основное содержимое прокручивается отдельно.

## Обновление
1. Закройте «Мост буфера» на Windows.
2. Замените WiFiClipboard.exe в папке установки новым файлом.
3. Запустите программу и обновите страницу на iPhone в Safari.

Все ресурсы встроены в EXE. Папка source нужна только для изменения и пересборки. Полученные файлы и сохранённые подключения при замене EXE сохраняются. 

## Смена Wi-Fi
Подключите Windows и iPhone к одной новой сети. Примерно через 2–3 секунды программа обновит адреса и QR-код. Откройте постоянный адрес .local или отсканируйте свежий QR с IP. Закладка с числовым IP предыдущей сети не может автоматически узнать новый адрес компьютера.

Если Windows блокирует подключение, запустите «Разрешить-локальную-сеть.ps1» и подтвердите запрос администратора. Он создаёт правила только для WiFiClipboard.exe и локальной подсети: TCP 8765 и UDP 5353, профили Private и Public. Используйте в доверенных сетях. Если новый IP не открывается даже с разрешением Windows, проверьте VPN и изоляцию устройств на роутере.

## Перетаскивание и папки
Перетащите файлы или папки из Проводника в любую часть окна программы. Также доступны «Выбрать файлы» и «Выбрать папку → отправить ZIP». Работает копирование файлов и папок через Ctrl+C в Проводнике.

Папка на Windows автоматически превращается в один ZIP с вложенными и пустыми папками. Исходная папка остаётся на месте. Упаковка выполняется в фоне; результат появится в списке на iPhone. Предел: 10 ГиБ исходных данных, 100 000 элементов, 64 уровня вложенности; итоговый ZIP также не должен превышать 10 ГиБ. Ссылки и junction внутри папки не архивируются: выберите обычную папку. На iPhone ZIP можно открыть встроенным приложением «Файлы».

Временные ZIP хранятся рядом с программой в .WiFiClipboard-archives. После снятия доступа или штатного закрытия программы они удаляются. Обычные выбранные файлы и исходные папки программа не удаляет.

## QR-код подключения
Нажмите «QR-код подключения» на Windows и наведите камеру iPhone на код. Откроется страница Safari с заполненным кодом подключения. Введите название, например «Мой iPhone», и нажмите «Подключить iPhone».

В выпадающем списке QR можно выбрать постоянный адрес .local или IP. QR строится на компьютере, без сторонних сервисов. Windows и iPhone должны видеть друг друга в локальной сети. Если .local не открывается, выберите QR с IP.

Для значка на экране «Домой» используйте режим закладки Safari: «Поделиться» → «На экран Домой» → выключить «Открывать как веб-приложение». Так при открытии файлов сохраняется навигация Safari.

## История передачи
Кнопка «История передачи» на Windows и раздел «История передачи» в Safari показывают последние 300 событий: время, имя файла, направление, устройство и результат. История сохраняется после перезапуска. Для текста сохраняется событие без содержимого буфера.

«Передан Safari» означает, что Windows передал данные браузеру; Windows не может проверить, сохранил ли iPhone файл в «Файлы». «Очистить историю» удаляет записи, сохраняя сами полученные файлы.

## Продолжение после обрыва Wi-Fi
**iPhone → Windows:** файл отправляется частями по 2 МиБ. При потере связи страница ждёт восстановления и продолжает автоматически. Нажмите «Приостановить отправку», чтобы остановить ожидание, затем «Отправить / продолжить» для возобновления.

Полученные части сохраняются на диске и переживают перезапуск программы Windows. Если Safari закрыт или перезагрузил страницу, выберите тот же исходный файл и нажмите «Отправить / продолжить». Перед продолжением программа проверяет содержимое уже принятых частей. Не выбирайте изменённую копию. Незавершённые загрузки хранятся до 7 дней; «Отменить незавершённую загрузку» удаляет их части. При нескольких файлах завершённые файлы остаются на Windows.

Оставляйте Safari открытым во время отправки. iOS может приостанавливать работу страницы в фоне.

**Windows → iPhone:** сервер поддерживает HTTP Range и ETag. При обрыве используйте продолжение в менеджере загрузок Safari, если он его предлагает. Автоматическое возобновление определяет Safari. Держите программу Windows открытой и не изменяйте исходный файл. Если Safari предлагает только начать заново, откройте страницу файла и повторите скачивание. Ссылки на отдельные файлы действуют до 7 дней в текущем запуске программы и отзываются при снятии доступа или отключении устройства.

Снятие доступа к файлам Windows прекращает их скачивание; отправка файлов с iPhone при этом продолжается.

## Устройства
В окне Windows нажмите «Устройства». Выберите подключение, задайте название и нажмите «Переименовать» либо «Отключить выбранное». Отключение отзывает только его доступ и останавливает его передачи; остальные подключения остаются активными. Названия и отзыв сохраняются после перезапуска.

На iPhone раздел «Это устройство» позволяет изменить собственное название. Сохранённые подключения старой версии подхватываются автоматически и сначала называются «iPhone (сохранённое подключение)». Это подключения браузеров: приватная вкладка или другой браузер считаются новым подключением. Максимум — 16.

## Где находятся данные
- Полученные файлы: папка «Полученные файлы» рядом с программой.
- Незавершённые загрузки: служебная подпапка .WiFiClipboard-resume в «Полученных файлах» (не перемещайте её во время передачи).
- Подключения, имена, история и постоянное имя: %LOCALAPPDATA%\WiFiClipboard.
- История содержит имена файлов и устройств, но не содержимое текстового буфера.

HTTP работает в доверенной локальной сети без шифрования. Сеть с изоляцией клиентов может запрещать связь даже при одинаковом названии Wi-Fi.

## Проверка и сборка
В папке source есть build.ps1 для компилятора .NET Framework 4.x, встроенного в Windows. Нужна версия .NET Framework 4.5 или новее для ZIP. Node.js и Python для работы программы не нужны.

WiFiClipboard.exe --self-test путь-к-отчёту запускает локальные проверки с тестовыми файлами и буфером в памяти. Для JavaScript: node source/frontend-tests.cjs. Результаты готовой сборки находятся в ПРОВЕРКА.txt и ПРОВЕРКА-JS.txt. Safari на физическом iPhone проверяется пользователем; локальные тесты моделируют обрывы связи и потерю ответов.
