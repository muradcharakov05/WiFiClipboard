# WiFiClipboard — Мост буфера

Обмен текстом, файлами и папками между Windows и iPhone по локальной сети Wi-Fi. На iPhone используется Safari.

**Текущая версия: 7.1.**

[Скачать программу для Windows](dist/WiFiClipboard.exe?raw=true) · [Подробная инструкция](docs/ИНСТРУКЦИЯ.md)

## Возможности

- Передача текста Windows ↔ iPhone.
- Передача файлов любого типа, до 10 ГиБ на файл.
- Перетаскивание файлов и папок из Проводника.
- Автоматическая упаковка папки Windows в ZIP, включая вложенные и пустые папки.
- QR-код для открытия страницы подключения с заполненным кодом.
- Сохранённые подключения: имена устройств, переименование и отзыв отдельного подключения.
- История последних 300 событий, сохраняемая после перезапуска.
- Отправка с iPhone частями по 2 МиБ с автоматическим повтором после обрыва связи.
- Продолжение незавершённой отправки после перезапуска Windows или повторного выбора файла в Safari, с проверкой уже полученных частей.
- HTTP Range и ETag для докачки через менеджер загрузок Safari.
- Постоянный локальный адрес .local с резервным подключением по IP.

В версии 7.1 исправлены размеры окна Windows, прокрутка и доступность последней кнопки при увеличенном масштабе экрана.

## Быстрый запуск

1. Скачайте [WiFiClipboard.exe](dist/WiFiClipboard.exe?raw=true) и поместите его в отдельную папку с правом записи.
2. Подключите Windows и iPhone к одной доступной локальной сети и запустите EXE.
3. В окне Windows нажмите «QR-код подключения» и наведите камеру iPhone на QR.
4. В Safari задайте название подключения и нажмите «Подключить iPhone».
5. Перетащите файлы или папку в окно Windows либо выберите файлы для отправки на странице iPhone.

Для ярлыка: Safari → «Поделиться» → «На экран Домой» → выключите «Открывать как веб-приложение», чтобы сохранялись элементы навигации Safari.

## Особенности

- Устройства должны иметь возможность соединиться друг с другом по локальной сети. Изоляция клиентов в гостевой или общественной сети может препятствовать работе.
- HTTP не шифрует обмен: используйте доверенную локальную сеть. Подключение защищено кодом сопряжения и индивидуальными ключами браузеров.
- iOS требует действия пользователя для копирования и вставки; фоновая работа страницы Safari ограничена системой.
- После закрытия Safari для продолжения отправки нужно снова выбрать тот же файл. Полученные части хранятся до 7 дней.
- Докачкой на iPhone управляет Safari. Держите программу Windows открытой и сохраняйте исходный файл доступным.
- Полученные файлы находятся в папке «Полученные файлы» рядом с EXE. Настройки, история и отпечатки ключей устройств — в %LOCALAPPDATA%\WiFiClipboard.

## Сборка

Программа написана на C# / Windows Forms и использует .NET Framework 4.5 или новее. Все HTML, JavaScript и иконки встроены в EXE. Для работы готовой программы Node.js и Python не требуются.

В PowerShell из корня проекта:

~~~powershell
./source/build.ps1
~~~

Собранный WiFiClipboard.exe появится в корне проекта. Готовая сборка версии 7.1 находится в dist/.

## Проверки

~~~powershell
./WiFiClipboard.exe --self-test "$PWD/self-test.txt"
node ./source/frontend-tests.cjs
~~~

Серверные проверки используют временные файлы и буфер в памяти, не изменяя системный буфер обмена. Проверки JavaScript моделируют обрыв соединения, потерю ответа сервера, продолжение очереди и проверку содержимого повторно выбранного файла.

Версия 7 прошла 142 проверки сервера и 25 проверок JavaScript. Для исправления 7.1 дополнительно проверено расположение окна и последней кнопки при масштабах 100%, 125% и 150% в области экрана высотой 720 пикселей.
